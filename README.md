## 🔐 Zero Trust Security

Zero Trust is a modern security approach based on the principle:

> **"Never Trust, Always Verify."**

Unlike traditional security models that often trust users or devices based on their location inside a network, Zero Trust continuously verifies access based on factors such as identity, device security, application access, and security policies.

The internship helped build an understanding of how Zero Trust principles can be applied to modern cloud and enterprise environments.
